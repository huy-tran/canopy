1jNavigation model and keyboard
Navigation model
Two levels: project, then session. The sidebar shows both. The main area shows one project at a time, as Terminals or Overview.
Layout belongs to the project. Each project remembers tabs, split or grid, pane order and which pane had focus, so switching projects puts you back where you were.
Waiting is a queue. "Waiting on you" lists every session that needs input across all projects, oldest first. Ctrl Shift J jumps to the next one, focusing its pane.
Below about 900px the sidebar collapses to an icon rail with an amber dot per waiting project. Hovering an icon opens a flyout with its sessions; the palette covers the rest.
The terminal keeps the keyboard. App shortcuts use Ctrl Shift, Ctrl Alt or Alt plus a digit, so Claude Code's own keys (Esc, Ctrl C, Shift Tab, Ctrl R) pass straight through.
Fonts. Terminals default to JetBrainsMono Nerd Font (configurable), so status-line icons from your Claude Code mods render. The mockups use plain JetBrains Mono as a stand-in.
